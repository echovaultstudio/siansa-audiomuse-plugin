      Loudness & keys

      What the Siansa app levels the volume, shapes its fades and mixes in key by: each song's loudness (EBU R128), how it starts and ends, and its key. Measured here from each song's file, or taken from the Siansa plugin on AudioMuse-AI when it already had them.

        Genres

        Each song's genres from its sound alone (Essentia's Discogs-EffNet, 400 Discogs styles): a song is in every style it scores 0.15 or more, and always in its best one. Siansa's genre list, genre pages and genre radios go by this; its tags are shown beside it and play no part.

        Descriptions

        Each genre's page in the app opens with a short description from Wikipedia. They're fetched in the background and kept (a found one for 90 days, a genre Wikipedia has nothing on for a week, one it couldn't be asked about for half an hour), so the app shows them at once.

                              Setup

                              What Siansa Beats connects to, who may open it, and how the Siansa app connects to it. All of it is set here: nothing secret goes in the container's YAML.

                              You can tidy the container's settings

                              These are still in the container's YAML and are no longer read: . They were taken over once (hashed or encrypted) and are set on this page since, so you can delete those lines.

                              Music servers

                              Navidrome, Emby and Jellyfin, as many as you have, and more than one user of the same server (each sees the libraries that user may). A song two servers have is found by its file or its tags and analysed once. The default server is the one the Siansa app is answered for when it doesn't say which it plays from.

                                Add a server or a user

                                No password is kept as you type it. Emby's and Jellyfin's is used once to sign in and not kept: only the sign-in the server gives is, encrypted. Navidrome's has to be said to Navidrome each time, so it's kept encrypted. None is ever shown, logged or put in a report, and Siansa Beats only reads from the server.

                                AudioMuse-AI

                                What it has worked out about each song (how it sounds, its moods and genres) is taken over from it, so nothing is analysed twice; Siansa Beats then answers similar songs, albums and artists, song paths, blends and moods itself. A song's tempo is never AudioMuse-AI's: it's the one Beat This! finds here.

                                The token is kept encrypted and never shown again.

                                Access

                                The app's key, shown this once (only its hash is kept). Copy it into Siansa now:

                                Only a hash of the password and of the key is kept: neither can be read back. Your browser asks for the password (user name siansa). Forgotten it? Start the container once with BEATS_RESET_ACCESS=yes.

                                The model

                                Genres by sound

                                Which model hears each song's styles, for the genre pages and the genre radios. Both give the same 400 Discogs styles, so changing the model changes nothing in how genres are named or read; every song is heard again with the new one (its old styles stay in use until then).
